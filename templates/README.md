# Templates

Copy one of these files when you start a note. Leave the templates themselves unchanged so the next note starts blank.

| Template | Copy into | Use for |
| --- | --- | --- |
| [note.md](note.md) | `notes/` | Concepts, checklists, reading notes |
| [lab.md](lab.md) | `labs/` | An isolated environment and what you verified |
| [topic-stub.md](topic-stub.md) | `notes/` | A new topic that only has goals so far |
| [cve-study.md](cve-study.md) | `cves/` | One public advisory: impact, affected versions, official fix |

[`cves/_template.md`](../cves/_template.md) and [`notes/_template.md`](../notes/_template.md) are the short forms already sitting next to existing notes. Prefer the files in this folder when you want the learning-goal headings.

## How to contribute a template change

Change a template only when several notes need the same new heading. Keep fields empty. Do not embed examples of exploits, payloads, or attack steps. The policy is in the [root README](../README.md#no-exploit-code).
