# References

An index of public documentation for these notes. Link out. Do not copy long passages in, and do not link to exploit write-ups, proof-of-concept repositories, or malware samples.

## How to add a reference

1. Add the title, publisher, and URL under the matching heading in [`public-docs.md`](public-docs.md).
2. Add one line on why it is useful for study (a concept, a control, or a patch advisory).
3. Prefer primary sources: vendor advisories, standards bodies, and project security pages.
4. When a note relies on a reference, link the anchor from the note instead of repeating the URL.

## Scope

Sources here support defensive study: protocols, secure development, incident-response policy, and vulnerability advisories. If a page's main content is a reproduction guide, leave it out.
