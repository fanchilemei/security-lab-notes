# Public docs

Primary sources for the starter notes. Add a line when you actually use a document.

## Networking

- [RFC 791, Internet Protocol](https://www.rfc-editor.org/rfc/rfc791) — what an IP datagram is for
- [RFC 9293, Transmission Control Protocol](https://www.rfc-editor.org/rfc/rfc9293) — current TCP specification
- [RFC 768, User Datagram Protocol](https://www.rfc-editor.org/rfc/rfc768) — UDP
- [RFC 1034, Domain Names — Concepts and Facilities](https://www.rfc-editor.org/rfc/rfc1034) — DNS concepts
- [RFC 8446, The Transport Layer Security (TLS) Protocol Version 1.3](https://www.rfc-editor.org/rfc/rfc8446) — TLS 1.3
- [MDN: Transport Layer Security](https://developer.mozilla.org/en-US/docs/Web/Security/Transport_Layer_Security) — shorter web-oriented overview

## Secure development

- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — named risk categories for web applications
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) — preventive controls
- [OWASP Secure Coding Practices Quick Reference](https://owasp.org/www-project-secure-coding-practices-quick-reference-guide/) — checklist-style practices
- [CWE](https://cwe.mitre.org/) — common weakness identifiers, for naming a class of bug
- [NIST SSDF, SP 800-218](https://csrc.nist.gov/pubs/sp/800/218/final) — secure software development practices

## Incident response and advisories

- [NIST SP 800-61 Rev. 3](https://csrc.nist.gov/pubs/sp/800/61/r3/final) — incident response aligned to CSF 2.0 (current revision)
- [NIST Cybersecurity Framework 2.0](https://www.nist.gov/cyberframework) — Govern, Identify, Protect, Detect, Respond, Recover
- [CISA cybersecurity best practices](https://www.cisa.gov/topics/cybersecurity-best-practices) — public operational guidance index
- [National Vulnerability Database](https://nvd.nist.gov/) — public CVE records
- Vendor and project security advisories — cite the specific advisory from the `cves/` note rather than a search page
